Use this skill when you need to design data schemas and models.

## Steps

1. **Understand Requirements**: Review functional requirements and data domain
2. **Identify Entities**: Define the core entities and their attributes
3. **Define Relationships**: Map relationships between entities (one-to-one, one-to-many, many-to-many)
4. **Specify Constraints**: Document validation rules, unique constraints, and foreign key relationships
5. **Version Control**: Assign versioning to schema changes
6. **Document**: Write the schema specification in `03-designs/`
7. **Validate**: Review the schema against `rules/architecture.md` and edge cases and future growth needs
