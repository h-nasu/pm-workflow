Use this skill when you need to implement a new feature.

## Steps

1. **Plan**: Create a plan under `01-plans/` with problem understanding, assumptions, and proposed approach
2. **Specify**: Define functional and non-functional requirements in `02-specifications/`
3. **Design**: Create architecture and component design in `03-designs/`
4. **Task Breakdown**: Create tasks in `04-tasks/`
5. **Implement**: Follow `rules/coding.md` and `rules/architecture.md` during implementation
6. **Test**: Write and run tests following `rules/testing.md` for the new feature
7. **Document**: Create or update client-facing documentation following `rules/documentation.md` under `docs/`
8. **Review**: Run the code review skill to verify quality
