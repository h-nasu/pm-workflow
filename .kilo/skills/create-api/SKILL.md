Use this skill when you need to implement a new API endpoint.

## Steps

1. **Plan**: Define the API purpose, endpoints, request/response shapes, and error codes
2. **Specify**: Write functional and non-functional requirements in `02-specifications/`
3. **Design**: Document the API contract, data flow, and integration points in `03-designs/`
4. **Task Breakdown**: Create tasks for implementation, testing, and documentation
5. **Implement**: Build the endpoint following existing API patterns and `rules/coding.md` in the codebase
6. **Test**: Write integration tests for all endpoints and error scenarios
7. **Document**: Create API documentation under `docs/api/endpoints.md`
8. **Review**: Run the code review skill to verify quality and contract adherence
