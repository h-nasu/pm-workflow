Use this skill when you need to review code changes for quality and correctness.

## Steps

1. **Gather Changes**: Collect the diff, PR description, and associated issues
2. **Check Correctness**: Verify the code does what the specification requires
3. **Check Standards**: Validate adherence to `rules/coding.md` and `rules/architecture.md`
4. **Check Tests**: Verify test coverage is adequate and tests are meaningful
5. **Check Documentation**: Confirm documentation is updated for changed behavior
6. **Check Security**: Look for security implications and vulnerabilities
7. **Report Findings**: Summarize issues with specific file references and recommendations
8. **Verify Fixes**: Confirm all feedback is addressed before approval
