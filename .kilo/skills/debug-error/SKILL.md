Use this skill when you need to diagnose and resolve errors or unexpected behavior.

## Steps

1. **Reproduce**: Identify the minimal steps to reproduce the issue
2. **Gather Evidence**: Collect logs, stack traces, error messages, and relevant context
3. **Hypothesize**: Formulate possible root causes based on the evidence
4. **Isolate**: Narrow down to the exact cause through systematic elimination
5. **Fix**: Implement the minimal fix that addresses the root cause, following `rules/coding.md`
6. **Verify**: Confirm the fix resolves the issue without introducing regressions
7. **Prevent**: Add a test case to prevent recurrence
8. **Document**: Record the root cause, resolution, and preventive measures in `08-issues/`

## Standards

- Adhere to the architecture guidelines in `rules/architecture.md`
