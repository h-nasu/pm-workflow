Use this skill when you need to create or update project documentation.

## Steps

1. **Identify Audience**: Determine who the documentation is for (developers, users, ops)
2. **Gather Information**: Review code, specifications, and design documents
3. **Draft**: Write documentation following the project's doc structure and `rules/documentation.md`
4. **Review**: Verify accuracy against the actual code behavior
5. **Format**: Apply consistent formatting and structure using project templates
6. **Place**: Save documentation in the correct location under `docs/`
7. **Update**: Ensure related documentation is updated to reflect changes

## Standards

- Follow the coding standards in `rules/coding.md`
